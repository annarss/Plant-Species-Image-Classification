# Plant-Species-Image-Classification

## A. Project Overview
● Brief description of the project
This project involves creating an image classification model using Teachable Machine. The model was trained using images of different plant classes. By providing labeled images for each plant category, the system learns to recognize patterns and features that distinguish one plant from another. After training the model, it can classify new images and predict which plant class they belong to along with a confidence score.
● Purpose of the image classification model
The purpose of the image classification model is to automatically identify and classify plant images based on their visual characteristics. This helps demonstrate how machine learning can be used to recognize objects in images. The project also aims to show how image classification models can assist in tasks such as plant identification, educational demonstrations, and basic applications of artificial intelligence in agriculture and environmental studies.
